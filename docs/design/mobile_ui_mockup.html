WITS & FOOLS — MOBILE UI

A touch-first redesign of every game screen, built landscape-primary around the dual-deck board. The hard problem is the match screen — two opposing hands, two draw piles, a bout, trump, a removed pile and progress meters — so the interaction model below is designed to keep that legible and tappable on a 6-inch phone.

How the information is organized — the three decisions that shape everything

1 · LANDSCAPE, ONE ORIENTATION

The board is a table with players facing each other — it only reads in landscape, like Hearthstone, Slay the Spire and Balatro on phones. Portrait would push cards below the 44px tap minimum. The whole game stays landscape so there's no rotation friction moving between map, shop and match.

2 · HERO ZONES vs REFERENCE ZONES

Only two things are touched constantly: your hand (bottom) and the bout (center). They get the space and the largest cards. Everything else — identity, decks, trump, removed pile, log — is reference, compressed to the screen edges as chips, never competing with the play area.

3 · TAP TO INSPECT, THEN ACT

Touch has no hover, so a card's full text can't live on the card. Tap a card → it lifts, an inspector shows its ability, and contextual action pills rise into thumb reach. A second tap (or drag-up) commits. Every commit is two clear steps, never an accidental play.

4 · PROGRESS IS ALWAYS VISIBLE

The win condition (shed every card) is a race-to-zero bar in each identity chip — the one number that matters, on screen at all times. Resource (Intel/Fury/Favor/Luck) shows as pips, not text. Counts (hand, deck) are single digits in badges.

5 · ONE PRIMARY ACTION, BOTTOM-RIGHT

The phase's single commit — END BOUT / TAKE CARDS / disabled — lives under the right thumb and changes label + color with state. Secondary tools (log, menu) are small round buttons top-right, out of the play path.

6 · REFERENCE EXPANDS ON DEMAND

The event log, full deck, and removed pile collapse to tappable counters; tapping opens a sheet. Transient events (ability fired, trump changed) flash as a toast and append to the log, so nothing critical is hover-only or blink-and-miss.

7 · SAFE AREAS RESPECTED

Identity chips inset from the left notch / Dynamic Island; the hand and all bottom bars sit a clear 24px above the home-indicator strip so a play-swipe never fights the system home gesture. The right thumb owns the commit button; the left thumb owns the log.

This revision incorporates an independent cold mobile-UX review: the hand was lifted off the home strip, card/label type raised from 7px to a readable tier, tap targets brought to ≥44px, the log moved into thumb reach, map nodes enlarged & spaced, and the core multi-card pile-on flow (state 3) and event-log sheet (state 10) added.

TOUCH GRAMMAR — the complete gesture set

  • Tap a hand card → select + lift + inspector + action pills. Tap again on the card, or the pill, to commit. (Replaces desktop click-to-play and hover-tooltip.)
  • Tap an action pill → Attack / Use Ability / Play / ✕ cancel. Only legal pills appear (engine CanAttackWith / AbilityValidForPhase).
  • Drag a card up → fast-path: into the bout = attack; onto a glowing slot = defend. Same legality rules; tap path remains for precision & accessibility.
  • Defend → select card first, legal attack slots pulse gold, tap one to cover (CanDefendSlotWith respects rank, trump and rank-bonus chips).
  • Primary button → context-driven single commit: END BOUT (attacker, all parried) / TAKE N CARDS (defender) / disabled (waiting).
  • Long-press anything → large read-only card inspector with flavor; never commits.
  • Bottom sheet → optional-ability choice, stack put-back prompt, peek/scry reorder. Modal, dismissable.
  • 📜 log button (bottom-left, left thumb) → opens the full Table Talk history; ☰ menu (top-right) holds settings & Concede (with a confirm step). 📚 opens the deck viewer on meta screens.
  • Tappable reference chips → tapping your deck pile opens the deck viewer; the trump card shows a one-line rule reminder; the removed counter opens the removed-pile sheet. They're enlarged enough to hit, but never block the play path.
  • Defend edge case → while a card is held for defense, tapping a different hand card re-selects it (recomputes the legal slots); tapping ✕ or the held card deselects.

WHAT MOVED, AND WHY

  • Desktop's hover tooltip → tap-to-inspect (touch has no hover).
  • Desktop's always-open event log panel → collapsed to a toast + history button (screen real estate).
  • Desktop's two identity panels + separate resource/deck labels → two compact corner chips fusing avatar, counts, pips and race bar.
  • Desktop's wide action zone → one thumb-zone button bottom-right; phase text rides on the ribbon + button subtitle.
  • Trump card, removed pile → edge chips; they're reference, not interactive during normal play.
